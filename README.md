# 诗路行者 · 大庾岭贬谪诗人行迹数字地图

「诗路行者」是一个数字人文（Digital Humanities）全栈网站：以唐宋贬谪诗人翻越大庾岭梅关古道的行迹为叙事主线，将诗人行迹、过岭诗作与情感曲线绘制于交互地图之上。

## 功能

- **主站（滚动长卷）**：项目缘起、诗路三叠、地图速览、情感曲线、AI 视频
- **数字地图 `/map`**（核心）：Leaflet 交互地图
  - 26 位唐宋诗人贬谪/行旅路线可视化（含安史之乱前初唐名录：张说、宋之问、沈佺期、杜审言、阎朝隐、张九龄、李峤、苏味道、卢照邻、房融、王昌龄、樊晃、刘希夷等）
  - 35 个历史地理节点、71 首过岭诗作，点击节点查看在此创作的诗人与诗作
  - 诗人导览（动画播放 + 里程等比进度条 + 侧边信息卡）、双诗人行迹对比
  - 多套底图主题（青绿山水 / 水墨 / 绢帛 / 夜色）与清代古地图瓦片图层
  - AI 导游（流式对话）、背景音乐
- **后台管理**：知识库（诗人/节点/诗作/导览词）与内容管理，Kimi 登录鉴权
- **降级容错**：数据库不可用时前端自动切换静态兜底数据，站点仍可浏览

## 技术栈

React 19 · TypeScript · Vite 7 · Tailwind CSS 3.4 · shadcn/ui · Leaflet 1.9 · GSAP · Lenis
后端：tRPC 11 · Hono · Drizzle ORM · MySQL/TiDB · Kimi OAuth · Docker

## 本地运行

```bash
npm install
cp .env.example .env   # 填入 DATABASE_URL / APP_ID / APP_SECRET 等
npm run db:push        # 同步数据库结构
npm run dev            # 开发
npm run build && npm run start   # 生产
```

## 数据说明

诗人名录与诗作来源：《全唐诗》、吴强《唐代大庾岭诗路研究》、周婷《唐代梅关古道诗歌研究》、姚俊娜《唐人岭南行程与诗歌关系研究》、梁智谦《唐代岭南贬谪诗歌研究》等（整理人：王可钰）。

## 关于本仓库

本仓库托管项目**源代码**。图片 / 视频 / 古地图瓦片（`public/` 下二进制资源，约 4000+ 瓦片）与 `.env` 凭据未包含在内；完整可运行版本部署于 Kimi 平台。
